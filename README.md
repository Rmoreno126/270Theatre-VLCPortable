# 270° Study Theatre — Portable Kiosk

An out-of-the-box kiosk system designed for the 270-degree Study Theatre. This repository includes a fully-configured portable instance of VLC Media Player and a custom web-based control panel.

## 🚀 One-Minute Setup

### STEP 1 — Download the Project
* Clone this repository or click the green **Code** button on GitHub and select **Download ZIP**.
* Extract the contents anywhere on your machine (e.g., your Desktop).

### STEP 2 — Add the Videos (Required)
Due to GitHub file size limits, the heavy 360° video assets are hosted separately.
* Download the video assets ZIP from the Google Drive link provided in our project brief.
* Extract the video files and drop them directly into this folder path within the project:
  `App/vlc/Videos/`

### STEP 3 — Run the Kiosk
1. Double-click `VLCPortable.exe` to boot up the media engine. *(The VLC Web Interface and security password are already pre-configured inside this build!)*
2. Open any web browser (Chrome, Edge, or Firefox) and navigate to:
   `http://localhost:8080`
3. When prompted by the browser, leave the **username blank** and type the password: `theatre270`

The custom 270° Study Theatre user interface, scene triggers, Humboldt branding, and localized video playback controls will work instantly out of the box.
