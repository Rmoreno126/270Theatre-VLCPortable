▶ Play from USB Drive

Plug in your USB drive, then follow the steps below to get the file path.

How to get the file path ▾
  1. Plug in your USB drive — Windows will assign it a drive letter (e.g., D: or E:).
  2. Open File Explorer and navigate to your video file on the USB drive.
  3. Hold Shift and right-click the video file.
  4. Select "Copy as path" from the menu.
  5. Paste the copied path into the field below and click Play to Wall.
